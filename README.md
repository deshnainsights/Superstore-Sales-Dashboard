# Superstore Sales Dashboard

## Project Overview

This project presents an interactive Power BI dashboard developed using Superstore sales data. The dashboard provides insights into sales performance, profitability, customer segments, regional trends, and product categories.

## Business Problem

Retail businesses need visibility into sales performance and profitability across regions, customer segments, and product categories. This dashboard enables decision-makers to identify growth opportunities and improve operational performance.

## Dashboard Features

* Total Sales Analysis
* Profit Analysis
* Regional Performance
* Customer Segment Analysis
* Product Category Performance
* Interactive Filtering and Drill-Down

## Key Metrics

* Total Sales
* Total Profit
* Total Orders
* Profit Margin
* Sales by Region
* Sales by Category
